# Push Notification

A tiny Node/TypeScript program for the make.fun bounty "The Perfect Pickup Line". It writes one pickup line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`), after validating that the line is a single non-empty line of at most 200 characters.

Entry line:

> Are you a push notification? Because I swore I would ignore you, and now I check for you every three minutes.

Run it with: `node main.ts`
